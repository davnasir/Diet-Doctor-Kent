## 📌 About The Project

**Diet Doctor Kent** is a modern healthcare and nutrition-focused website template created with a clean and professional design approach.

The project is designed to provide an attractive online presence for **diet doctors, nutritionists, health consultants, clinics and wellness professionals**.

The interface focuses on:

* ✨ Clean & modern UI
* 📱 Fully responsive layout
* 🥗 Nutrition & healthcare-focused design
* 🎨 Professional visual presentation
* ⚡ Lightweight frontend structure
* 🧩 Easy customization

---

## 🚀 Key Features

### 🩺 Professional Healthcare Design

A modern interface suitable for diet doctors, nutritionists, health consultants and wellness professionals.

### 📱 Fully Responsive

The website layout is designed to work smoothly across:

## 💻 Getting Started

Follow the steps below to run the project locally.

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/davnasir/Diet-Doctor-Kent.git
```

### 2️⃣ Navigate to the Project

```bash
cd Diet-Doctor-Kent
```

### 3️⃣ Open the Website

Simply open:

```text
index.html
```

in your preferred browser.

For the best development experience, you can also use **Visual Studio Code + Live Server**.
